故障闭环审计台

深海采集站的失效动作可能不产生回执。本台精确判定：是否存在一条已发生故障的无限执行与一条 从未发生故障的无限执行，其可观察回执序列完全相同（即故障可能被一条始终正常的执行无限期伪装）。

      判定语义与裁决说明

      • 回执序列：执行依次经过的非静默迁移的回执所构成的序列；两个序列“完全相同”指逐项相等（不做字符拼接比较）。静默迁移不产生回执。
      • 精确判定：在双厂验证器（twin plant）图上判定——存在“已发生故障的无限执行”与“从未发生故障的无限执行”回执序列相同，当且仅当某个旗标为一故障一正常的可达诊断对位于一条两侧均可推进的闭环上。该条件充分必要，非有限回放、非仅比较位置名称。
      • 裁决顺序（稳定）：共同前缀回执数 → 前缀步数 → 前缀迁移标识序列字典序 → 闭环回执数 → 闭环步数 → 闭环迁移标识序列字典序。同一规程多次提交结论一致。
      • 异步与过期任务：计算在 Web Worker 中执行。计算期间修改规程或点击“取消计算”会使在途任务过期；过期任务一律不得改写当前草稿与结果。
