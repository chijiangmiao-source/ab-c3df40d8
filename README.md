# 深海采集站 · 故障闭环审计页

深海采集站的失效动作可能不产生回执。本工具供值班工程师复核：**任一故障发生后，是否可能被一条始终正常的执行无限期伪装**——即是否存在一条“已发生故障的无限执行”与一条“从未发生故障的无限执行”，其可观察回执序列完全相同。

## 判定语义

- 工程师在浏览器录入：有限位置集、初始位置、带唯一标识的迁移；每条迁移标为**故障**或**正常**，并填写 **ASCII 回执**（可打印 ASCII，非空）或勾选**静默**（不产生回执）。
- 执行的回执序列 = 依次经过的非静默迁移的回执所构成的序列；两个序列“完全相同”指**逐项相等**（不做字符拼接比较）。
- 提交后精确判定上述执行对是否存在：
  - **不可诊断**：页面按“回执长度 → 迁移标识”稳定裁决，展示**最短共同前缀**、**可重复闭环**与**两侧逐步迁移对应**（前缀表与闭环表各一张，故障侧/正常侧分列）。闭环可无限重复，故两条执行均为无限。
  - **可诊断**：展示**已检查的诊断对摘要**（诊断对总数、同步边数、旗标组合计数、混合旗标对清单）。

## 判定方法（非有限回放）

双厂验证器（twin plant）：状态为 `(左位置, 左旗标) × (右位置, 右旗标)`，旗标 ∈ {未故障 N, 已故障 F}。静默迁移单侧推进；带回执迁移两侧按回执相等同步推进。精确判定条件（充分必要）：

> 某个旗标为 (F,N) 或 (N,F) 的可达诊断对，位于一条**两侧都至少推进一步**的闭环上。

该闭环保证两侧执行均可无限延伸且回执序列逐项相同；反之，任意这样的执行对都可在验证器中对齐并找到上述闭环。裁决顺序（稳定、确定）：共同前缀回执数 → 前缀步数 → 前缀迁移标识序列字典序 → 闭环回执数 → 闭环步数 → 闭环迁移标识序列字典序。

## 交互保障

- **错误定位**：悬空目标（迁移源/目标或初始位置不在位置集中）、重复迁移标识、非法回执（非可打印 ASCII、非静默却为空）会定位到具体输入框，并**清除旧结论**。
- **过期任务隔离**：计算在 Web Worker 中异步执行；计算期间修改规程或点击“取消计算”会使在途任务过期，过期任务的回包一律被丢弃，**不得改写当前草稿与结果**；旧结论保留并标记“可能已过期”。
- **资源上限**：诊断对数量超过上限（默认 50000）时如实报告“无法判定”，绝不给出猜测结论。

## 目录结构

```
src/diagnoser.js   判定核心（浏览器 / Worker / Node 三端共用）
src/server.js      静态服务器 + /healthz 健康检查（PORT 可调，默认 8080）
web/               页面（index.html / app.js / worker.js / styles.css）
scripts/build.js   构建：语法检查 + 装配 public/ + 引用校验
scripts/verify.js  核对：代码测试 + 构建检查 + 页面 HTTP 冒烟，以退出码报告
test/              node:test 用例（静默双环、可诊断回执、校验、裁决稳定性等）
Dockerfile / docker-compose.yml
```

## 本地运行（Node ≥ 18，零第三方依赖）

```bash
npm test            # 代码测试
npm run build       # 构建检查并装配 public/
npm start           # 启动页面，默认 http://localhost:8080（PORT=9000 npm start 可改端口）
npm run verify      # 一键核对：测试 + 构建 + HTTP 冒烟（退出码即结果）
```

## Docker / Compose

```bash
docker build -t abyss-fault-loop-audit .
docker run --rm -p 8080:8080 abyss-fault-loop-audit   # 健康检查：/healthz

# Compose（端口可调）：
APP_PORT=9000 docker compose up app                    # 页面服务
docker compose up --exit-code-from verify verify       # 核对服务：执行后退出，退出码即核对结果
```

`verify` 服务依赖 `app` 健康检查通过，依次执行：代码测试（静默双环 / 可诊断回执等）→ 构建检查 → 对 `http://app:$APP_PORT` 的页面 HTTP 冒烟，随后退出并返回退出码。
